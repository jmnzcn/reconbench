# Data license

[Creative Commons Attribution 4.0 International license (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).

Attribution: ReconBench, Ney Fred Jiménez Campos, https://github.com/jmnzcn/reconbench

The data is synthetic. It was generated with vendor-recovery-engine, whose generator builds vendors,
catalogs and prices from the UCI Online Retail II dataset (CC BY 4.0, https://doi.org/10.24432/C5CG6D) and
converts currencies with the European Central Bank's euro reference rates. No real vendor's data is included.
